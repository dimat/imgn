# imgn Models

## Available Models

### Gemini Pro (Nano Banana Pro)

- **ID**: `gemini-3-pro-image-preview`
- **Alias**: `pro`
- **Resolutions**: 1K, 2K, 4K
- **Quality**: Highest quality, best for final outputs
- **Speed**: Slower (~15-30s)
- **Best for**: Production images, detailed scenes, 4K output

### Gemini Flash (Nano Banana)

- **ID**: `gemini-2.0-flash-preview-image-generation`
- **Alias**: `flash`
- **Resolutions**: 1K, 2K
- **Quality**: Good quality, optimized for speed
- **Speed**: Fast (~5-10s)
- **Best for**: Prototyping, iterations, quick previews

## Comparison

| Feature | Pro | Flash |
|---------|-----|-------|
| Max resolution | 4K | 2K |
| Speed | Slower | Faster |
| Quality | Highest | Good |
| Image editing | ✅ | ✅ |
| Aspect ratios | All | All |

## Aspect Ratios

Both models support: `1:1`, `16:9`, `9:16`, `4:3`, `3:4`
